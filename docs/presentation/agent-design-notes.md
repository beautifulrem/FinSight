# FinSight Agent 化工程设计复盘

面向架构评审与技术交流的精简复盘，所有引用指标均可追溯至 `evaluation/results/` 与 `docs/results/` 中已提交的可复现产物。

## 1. 一句话定位

FinSight 将**经典可解释的查询智能底座**（FAIA 2026 论文核心，[DOI: `10.3233/FAIA261107`](https://ebooks.iospress.nl/doi/10.3233/FAIA261107)）与 **LangGraph 可验证研究 Agent** 结合：经典 ML 管路由、守卫和取证，LLM 只做复杂编排与表述，代码逐句核对每个数字与引用，无 API Key 时自动降级至确定性规划器。

## 2. 核心设计决策与取舍

| 决策 | 为什么这么选 | 代价与边界 |
|---|---|---|
| **经典 NLU 路由 + 混合执行图** | 路由和越界守卫必须可解释、低延迟、零成本；简单查询直接走确定性规划，复杂对比/归因/多跳才进规划预取的 LLM 循环。 | 词类/规则在全新问法上有 ~20% 路由误差（独立集 v2 首次 `0.801`）。 |
| **规划预取启动循环（`planner_prefetch`）** | 消除纯循环的首轮盲目选工具往返，P50 减半、TTFT 降至 ~3 s、LLM 调用降 ~35%。 | 工具精确率略降（预取偶尔多查一个工具），实网多花少量数据源请求。 |
| **逐句数值与引用校验器** | 将原运行级比对升级为同句 `evidence_id` 绑定（感知单位/精度/正负号），误放率从 `33.0%` 压至 **`0.92%`**，跨公司换数 `0%`。 | 证明的是「可追溯」而非「外部客观真实」；新闻投毒数字需靠输出安全层补防。 |
| **整句删除修复 + 先修引用再修订** | 旧子句裁剪仅 `26%` 可读；整句删除达 `100%` 可读且二次校验全过；`cite_repair` 优先补齐唯一命中引用，省去额外 LLM 修订调用。 | `QI_AGENT_VERIFY_DERIVED=1` 允许同句派生运算，误放率略升至 `1.05%`。 |
| **慢速模型策略（`prefer_composition`）** | GLM-5.3 Flash 上 Agent 与工作流+LLM 持平但 P95 达 `82 s`；`auto` 自动切换至工作流+LLM 组织答案（P95 `27 s`）。 | 限制了慢速模型在 `auto` 下的多轮探索自由度（`mode=agent` 仍可强制开启）。 |
| **不引入向量库 / 角色扮演多 Agent** | 金融实体、财务口径与时间窗对精确匹配极其敏感，经典检索 + 显式工具更可控；单 Agent + 代码校验已覆盖核心需求，避免 15× Token 开销。 | 长篇开放研报语义召回能力弱于成熟商用向量+重排系统。 |

## 3. 自研与复用边界

- **复用生态**：LangGraph（状态图、检查点、`interrupt/resume`）、MCP Python SDK 2.x、A2A SDK 1.x、FastAPI、PostgreSQL/psycopg、Prometheus/OTLP、React 19 + Lightweight Charts。
- **核心自研**：经典可解释 NLU 与仿冒/境外标的守卫、多源熔断与新浪/同花顺交叉核验、逐句数值校验器（`verifier.py`）、零 LLM 声明核查引擎（`claim_check.py`）、输出安全层（`output_safety.py`）、评测/红队/压力测试框架。

## 4. 代表性失败案例与系统级修复

1. **独立多轮集首次仅 `0.224`**：暴露自写测试与规则同源盲区 → 永久保留首次运行分数、建立暴露后标记规范，并系统补齐会话指代、省略承接与澄清恢复。
2. **模板路径红队 `0%`，但 LLM 路径泄漏 `2–10%`**：模型会把未拦截的文档投毒内容当作新闻转述 → 新增作用于全路径的 `output_safety.py`（删除推广/联系方式/喊单、标注单源或冲突数字、剔除与基本面矛盾的文档数字）与 Prompt `v4`。
3. **v1 离线种子与公司年报不符（五粮液/平安）**：未核对一手披露导致权威性受损 → 构建基于巨潮年报 PDF SHA-256 溯源的更正层（`structured_data_fix.json`）及显式会计口径标注（`ROE（加权）` vs 期末、归母 vs 总利润）。
4. **检索并发长尾（4 并发 `3.9 s`）**：`linear_kernel` 每次搜索重转置稀疏 TF-IDF 矩阵 → 缓存一次转置矩阵 `doc_matrix.T`，4 并发检索工具 P50 降至 `265 ms`。
5. **全仓安全与证据正确性审计（[PR #13](https://github.com/beautifulrem/FinSight/pull/13)）**：修复交易所后缀剥离错配指数、A2A/MCP 鉴权与跨租户防探测、凭据日志脱敏、ReDoS 及 `MiniRacer` V8 并发崩溃等 14 项 P1/P2 隐患。

## 5. 关键消融结论与局限

- **工具 + 校验是核心增益**：未接触测试集 v3 上，纯 LLM `0/130`，确定性流程 `0.769`，工作流+LLM `0.831`，规划预取 Agent **`0.869`**（`+0.100`，`p = 0.007`）。
- **核心局限**：仅实测两家 Flash 级模型；规则化比较/核查在全新句式上仍有漏判；LLM 路径仍有极低比例无数字投毒转述风险；人工盲测与竞品对比套件已就绪但尚未执行（见 [known-issues.md](../zh/known-issues.md)）。
