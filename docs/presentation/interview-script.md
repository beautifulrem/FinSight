# FinSight 项目讲解与问答提纲

一页纸口头讲解提纲，所有指标均对应 `evaluation/results/` 与 `docs/results/` 中已提交的可复现文件。深度取舍见 [agent-design-notes.md](agent-design-notes.md)。

## 1. 30 秒项目介绍

> FinSight 是一个已发表论文（FAIA Vol. 433 / DMI 2026，DOI `10.3233/FAIA261107`）并持续演进为生产级服务的 A 股证据优先研究 Agent。经典可解释 NLU 负责理解、越界守卫和路由；LangGraph 编排 9 个类型化只读工具；**答案里的每一个数字都由代码对照同一句引用的证据逐句核对**，最后由合规节点剔除交易建议；无 API Key 时同一张图自动回退到确定性规划器。
>
> 我们在独立作者编写、从未用于调优的 130 题测试集 v3 上实测：Agent 严格通过率 **86.9%**，确定性流程 **76.9%**，不调工具的纯 LLM 为 **0%**；校验器在 5,631 条篡改答案上的严格误放率仅 **0.92%**。

## 2. 两分钟架构走查

1. **`guard_in`（守卫与路由）**：输入守卫剥离用户侧提示注入 → 经典 NLU（含仿冒名/港美股守卫）+ 会话指代消解 → 可解释路由分流至 `refuse` / `clarify` / `workflow` / `agent`，并记录 `route_reasons`。
2. **双路径执行**：简单查询走确定性规划器并行取数；复杂对比/归因/多跳先预取规划工具再进入受步数、Token 与截止时间约束的 LangGraph LLM 循环。
3. **`verify`（逐句校验）**：按单位、精度与正负号校验每个数字是否归属本句引用的 `evidence_id`；缺引用先 `cite_repair`，否则定向修订一次，仍失败则整句删除。
4. **`compliance` & `output_safety`**：剔除买卖/仓位指令与文档推广、为单源或冲突数字加注出处提示、对未来预测加限定语、校验回答语种与新鲜度。
5. **工程与协议底座**：Postgres 多副本共享会话/任务/Trace/限流、MCP 双向集成、A2A 1.0（已通过官方 JS SDK 16/16 互操作）、Prometheus/Grafana/Jaeger 监控及 React 19 前端。

## 3. 三个可当场辩护的核心数字

| 指标 | 数值与口径 | 局限与诚实边界 |
|---|---|---|
| **校验器误放率** | 333 条正例、5,631 条篡改变体：严格误放 **`0.92%`**（派生数字默认 `1.05%`），跨公司换数 **`0.0%`**，正例通过 `100%`（`verifier_stress-round18.json`）。 | 证明「可追溯」而非「外部真值」；同证据多报告期难以区分；1% 微小扰动可能落入四舍五入容差。 |
| **独立测试集 v3 通过率** | DeepSeek 首次未接触运行，3 次重复一票否决：Agent **`0.869`** `[0.81, 0.92]` vs 确定性流程 `0.769`（`p = 0.007`）vs 纯 LLM `0/130`（`ablation-final4-deepseek-testv3-holdout.json`）。 | 仅覆盖两家 Flash 级模型；GLM 上 Agent 与组织答案持平且延迟高（已通过慢速模型策略路由至组织答案）。 |
| **Agent 延迟优化** | 剖析发现 95% 耗时在 LLM 往返与误报修订；通过分词修复、连接池、`cite_repair`、20 s 卡顿超时与规划预取，保留集 P95 从 `27.1 s → 15.4 s`，TTFT 减半至 `3.0 s`，成功率不降（`perf-*.json`）。 | 高并发下瓶颈转为上游网关限流（429）；预取使必要工具占比略降（`0.684 → 0.675`）。 |

## 4. 两个真实失败故事

- **独立多轮集首次 `0.224`**：自写开发集掩盖了规则过拟合。处理方式是原样提交首次分数，按类别修复并标注「暴露后」，再用全新的独立切片和未接触测试集检验泛化，同时让评测脚本自动作废高 429 降级运行。
- **模板路径红队 `0%`，LLM 路径泄漏 `2–10%`**：输入层只拦住约四成新型文档注入，模型会把假财报/诈骗群号当作新闻转述。通过新增 `output_safety.py` + Prompt `v4` A/B 验证，将全量 LLM 红队当作事实陈述降至 `0–3.4%`，最新定向切片降至 `0/16`。

## 5. 白板题提纲

```text
[提问] -> guard_in (去注入 / NLU / 仿冒与越界守卫 / 指代消解 / 路由)
           ├─ refuse (越界 / 港美股 / 注入)
           ├─ clarify (LangGraph interrupt -> /agent/resume)
           ├─ workflow (确定性规划 -> 并行工具 -> 模板或 LLM)
           └─ agent (规划预取 -> LLM ⇄ 9 只读工具，受预算与截止时间约束)
                               ↓
           verify (逐句数字与引用绑定 -> cite_repair / 修订1次 / 整句删除)
                               ↓
           output_safety + compliance (去建议 / 标单源 / 加预测对冲 / 免责声明)
                               ↓
           finalize (答案 + 证据台账 + trace_id + 成本 -> SSE / A2A / Prometheus)
```
