# 产品对比：FinSight 与问财、豆包、Kimi、Wind Alice、妙想

语言：[English](../comparison.md) | 中文

本文基于 2026 年 9 月公开的官方资料与媒体报道整理。**未直接实测任何商业产品**——缺乏公开独立验证的项均标注为「未验证」。

## 核心结论

**同花顺问财、Wind Alice、东方财富妙想、Kimi、豆包**在持牌实时数据库、多市场覆盖（A/港/美股、债券、研报）、客户端体验与用户规模上具有绝对优势，FinSight 并不试图替代它们的数据能力。

FinSight 的定位是**开源、可私有化部署的证据优先研究参考实现**，聚焦于上述商业产品均未公开量化的一项关键属性：**回答中每一句的每一个数字都由代码对照本句引用的证据自动核验**，并公开校验器误放率（5,631 条篡改答案严格模式误放 **0.92%**，正例通过 **100%**）、代码级合规去指令守卫、完整运行轨迹及原生 **MCP + A2A 1.0** 协议支持。

## 优势边界

- **商业产品优势**：持牌实时全市场数据、Excel/PPT/长研报生成、合规投顾牌照、自研金融大模型与成熟终端产品。
- **FinSight 差异点**：公开可复现评测集与失败案例、代码级逐句数字校验、零 API Key 确定性兜底、私有化租户隔离，以及完整的 MCP 与 A2A 1.0 协议互操作。
